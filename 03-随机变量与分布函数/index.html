第 03 讲 · 随机变量与分布函数

把抽象的"随机事件"翻译成"数字"——这是随机变量的全部价值。本讲从严格定义出发，刻画分布函数 $F(x)$，区分离散 / 连续 / 混合三种类型，最后给出二维联合分布与随机变量函数的分布。

本讲学习目标

学完本讲，你应该能够：

  1. 给出随机变量 $X:\Omega\to\mathbb{R}$ 的严格定义，并写出"可测"的两种等价说法
  2. 写出分布函数 $F(x)=P(X\le x)$ 的四条性质（单调、右连续、$F(-\infty)=0,F(+\infty)=1$）
  3. 区分离散（分布列 $p_k$）、连续（密度 $f(x)$）、混合型（既无密度也无分布列）三者的差别
  4. 在 $F(x)$、$p_k$、$f(x)$ 三者之间互相转换
  5. 写出二维联合分布函数 $F(x,y)$ 的三条性质，并区分联合 / 边缘 / 条件三种分布
  6. 用全概率公式推导条件密度 $f_{Y\mid X}(y\mid x)=\dfrac{f(x,y)}{f_X(x)}$
  7. 用分布函数法和单调公式法求 $Y=g(X)$ 的分布
  8. 写出 max、min、和、商 四类二元函数的密度公式（含卷积雏形）

知识图谱

一句话定位 随机变量 = 把"样本点 $\omega$"翻译成"数字 $X(\omega)$"的可测函数； 分布函数 $F(x)=P(X\le x)$ 是描述它的统一语言——离散、连续、混合型都能用 $F$ 刻画。
课件主线例子（贯穿本讲）
  1. 掷骰子：$X=\{\text{点数}\}\in\{1,\dots,6\}$ —— 离散型
  2. 等待时间：$X=\{\text{第 1 位顾客到达的时刻}\}\in[0,+\infty)$ —— 连续型
  3. 混合型反例：$P(X=0)=1/2$，否则 $X\sim\text{Uniform}(1,2)$（课件风格改编）
  4. 袋中 3 白 2 红，摸两次（王庆先第 2 讲课件 slide 10）—— 二维 / 边缘 / 条件 / 独立性
  5. $X(t)=A\cos(t+\Theta)$，$\Theta\sim U(0,2\pi)$（sjgc0-3 第 8 页）—— 单调公式法

本讲与前后章的关系

为什么必须把这一讲学扎实？
  • 第 04 讲"常见分布族"——Bernoulli / 二项 / Poisson / 均匀 / 指数 / 正态 / Gamma 全部都是本讲定义的特殊形态。
  • 第 05 讲"数字特征"——期望 $E(X)$ 用密度 / 分布列求和或积分，定义就在本讲。
  • 第 06 讲"多维随机变量"——本讲只做 2D 入门，更一般的 $n$ 维在那一讲展开。
  • 第 07 讲"随机过程"——一族按时间索引的随机变量 $\{X(t,\omega):t\in T\}$，本质上是本讲定义的"时间化"推广。
  • 第 08 / 10 / 12 讲的 Markov 链 / Poisson 过程 / Brown 运动 —— 全部要回到"随机变量"和"分布函数"这一层概念。

学习建议

  1. 先读 01（定义）+ 02（分布函数）——这两页是底层语言，后面所有内容都是它们的应用。
  2. 03（离散）+ 04（连续）——两对照读，看到 $F(x)$ 在两种情形下的不同形态（阶梯 vs 光滑）。
  3. 05（混合型）是反例，不要跳过——它告诉你"不是所有随机变量都能用 $p_k$ 或 $f$ 描述"。
  4. 06 + 07（二维 + 边缘 / 条件）——从"一维"过渡到"二维"，独立性是这部分的核心考点。
  5. 08（函数的分布）——本讲最需要练习的一节；建议跟着 $Y=X+Y$ 和 $Y=X^2$ 两个例子手算一遍。
  6. 玩动画页滑块，亲眼看到 $F(x)$ 形态随参数变化。
  7. 做自测 10 题。
