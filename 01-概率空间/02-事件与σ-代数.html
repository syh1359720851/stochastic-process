02 · 事件与 σ-代数

把"随机事件"从日常模糊概念变成集合论里可以严格操作的成员——这是概率论公理化最关键的一步。

1. 随机事件（Random Event）

直观含义 随机试验中可能被观察到、用集合语言描述的"事情"。一次试验的结果 $\omega$ 属于这个集合就说这件事发生了。

1.1 严格定义

样本空间 $\Omega$ 的子集 $A \subseteq \Omega$，称为一个随机事件（简称事件）。

事件 $A$ 在一次试验中"发生"，当且仅当此次试验的样本点 $\omega \in A$。

例子（掷骰子） $\Omega=\{1,2,3,4,5,6\}$。可定义的事件：
  • $A=\{2,4,6\}$："出现偶数"——骰子掷出 2、4、6 时事件 $A$ 发生。
  • $B=\{1\}$："出现 1 点"——这是一个基本事件。
  • $\Omega$ 本身是必然事件（必然发生）。
  • $\varnothing$ 是不可能事件（永远不发生）。

2. 事件的基本运算

设 $A, B \subseteq \Omega$，常用集合运算：

运算记号含义（人话）
并$A \cup B$$A$ 或 $B$ 至少一个发生
交$A \cap B$（或 $AB$）$A$ 与 $B$ 同时发生
差$A - B$$A$ 发生而 $B$ 不发生
补 / 对立$A^c = \Omega - A$$A$ 不发生
包含$A \subseteq B$$A$ 发生则 $B$ 必发生
易错点 "对立"和"互斥"不同：
  • 对立（互逆） $A, A^c$：$A \cap A^c = \varnothing$ 且 $A \cup A^c = \Omega$。
  • 互斥（不相容） $A, B$：$A \cap B = \varnothing$。互斥不一定对立（两者可都不是 $\Omega$）。

3. σ-代数（σ-Algebra）

直观含义 一个"够用"的事件集合——里面的事件互相取并、取补、做可列次并之后还是这个集合里的成员。概率 $P$ 必须能作用到这些事件上，所以它必须"封闭"。

3.1 严格定义

设 $\mathcal{F}$ 是由 $\Omega$ 的一些子集构成的非空集合类。若 $\mathcal{F}$ 满足：

  1. $\Omega \in \mathcal{F}$；
  2. （对补封闭）若 $A \in \mathcal{F}$，则 $A^c \in \mathcal{F}$；
  3. （对可列并封闭）若 $A_i \in \mathcal{F}$（$i=1,2,\dots$），则 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$。

则称 $\mathcal{F}$ 为 $\Omega$ 上的一个 σ-代数（$\sigma$-algebra，或 σ-域、随机事件体）。

等价刻画（教材补充） 由三条公理可推出（也是常见考题）：
  • $\varnothing \in \mathcal{F}$（由 ② 对 $\Omega$ 取补）
  • 对可列交封闭：$A_1, A_2, \dots \in \mathcal{F} \Rightarrow \bigcap_{i=1}^{\infty} A_i \in \mathcal{F}$（De Morgan）
  • 对差封闭：$A, B \in \mathcal{F} \Rightarrow A - B \in \mathcal{F}$
  • 对有限并 / 交封闭（可列并的特例）

4. 基本事件与可测空间

4.1 基本事件（Elementary Event）

仅含一个样本点的事件，称为基本事件，又叫原子（atom）。

$$\{\omega\} \in \mathcal{F} \quad \text{（对每个 } \omega \in \Omega \text{）}$$

4.2 可测空间（Measurable Space）

$\Omega$ 和 $\mathcal{F}$ 一起构成的二元组 $(\Omega, \mathcal{F})$ 称为可测空间。

$$\boxed{(\Omega, \mathcal{F})}$$

它定义了"哪些集合算事件"，但不定义"事件发生的可能性"——后者由下一讲的概率测度 $P$ 给出。

5. 几个重要 σ-代数

5.1 平凡 σ-代数（最小）

$$\mathcal{F} = \{\varnothing, \Omega\}$$

满足三条公理。给可测空间"配最小的事件结构"——只能谈"必然"和"不可能"，问不到任何中间事件。

5.2 离散 σ-代数（最大）

$$\mathcal{F} = 2^{\Omega} = \{A \mid A \subseteq \Omega\}$$

当 $\Omega$ 是有限集时，$2^\Omega$ 就是最大的 σ-代数，包含 $\Omega$ 的所有子集，共 $2^{|\Omega|}$ 个元素。

Ex · $n$ 元集合的 σ-代数（教材原例 Ex.3） 设 $\Omega = \{1, 2, \dots, n\}$，$\mathcal{F} = 2^\Omega$。问 $\mathcal{F}$ 有多少个元素？ $$\#\mathcal{F} = 2^n$$ 因为每个子集对应一个长度为 $n$ 的 0/1 向量（决定每个 $\omega$ 是否在子集中），共 $2^n$ 种。

5.3 由单点集 $\{x\}$ 生成的 σ-代数（教材 Ex.4）

Ex · $\mathcal{F}_\sigma(\{x\})$ $$\mathcal{F}_\sigma(\{x\}) = \{\varnothing, \{x\}, \{x\}^c, \Omega\} = \{\varnothing, \{x\}, \Omega\}$$ （因为 $\{x\}^c = \Omega - \{x\}$；把 $\Omega$ 视为全集时，这 4 个里实际有 3 个不同元素，如果 $\Omega = \{x\}$ 则退化为 $\{\varnothing, \Omega\}$。）

5.4 Borel σ-代数（连续情形）

当 $\Omega = \mathbb{R}$ 时，包含所有开区间 $(a, b)$ 的最小 σ-代数，称为 $\mathbb{R}$ 上的 Borel σ-代数 $\mathcal{B}(\mathbb{R})$。它是随机变量 / 随机过程理论的标准舞台。

6. 一个完整的可测空间例子（教材 Ex.2）

掷骰子 + 抛硬币 $$\Omega_1 = \{1,2,3,4,5,6\},\quad \Omega_2 = \{H, T\}$$ $$\Omega = \Omega_1 \times \Omega_2 = \{(i, j) \mid i=1,\dots,6,\ j \in \{H, T\}\}$$ $$\mathcal{F} = 2^\Omega = \{\text{所有 } \Omega \text{ 子集}\}，\ \text{共 } 2^{12} = 4096 \text{ 个}$$ 例如事件 $A = \{(1, H), (2, H), \dots, (6, H)\}$ = "硬币正面朝上"，$B = \{(1, H), (1, T)\}$ = "骰子掷出 1 点"。

7. 为什么需要 σ-代数？（一个高频疑问）

回答 因为我们不一定能给 $\Omega$ 的所有子集都定义概率。
  • 当 $\Omega$ 有限或可数时——可以，所有子集都"安全"。
  • 当 $\Omega = \mathbb{R}$ 或更复杂的空间时——存在不可测的子集（Vitali 集），无法给它们一致地定义概率。
  • σ-代数的存在，就是把"可以谈概率的事件"显式地圈出来，避免在不可测集上谈概率。

所以 $(\Omega, \mathcal{F}, P)$ 是一个三件套：空间 + 哪些子集可测 + 在可测集上赋概率。少一个都不行。

8. 自检问题

Q1 · 判断：以下哪个集合类是 σ-代数？
① $\mathcal{F}_1 = \{\varnothing, \Omega\}$ ② $\mathcal{F}_2 = \{A \subseteq \mathbb{R} \mid A \text{ 至多可数}\}$ ③ $\mathcal{F}_3 = \{\text{所有有限子集}\} \cup \{\mathbb{R}\}$

① ✅ 是 σ-代数（最小情形）

② ❌ 不是——两个可数集之并不一定可数（甚至可能不可数），对可列并不封闭。

③ ❌ 不是——$\mathbb{R}$ 不是有限集，但有限集的可列并不一定是有限集，不封闭。

Q2 · 设 $\mathcal{F} = \{\varnothing, \{1\}, \{2,3\}, \{1,2,3\}\}$。这是 $\Omega=\{1,2,3\}$ 上的 σ-代数吗？

检查公理：

  • ① $\Omega=\{1,2,3\}\in\mathcal{F}$ ✓
  • ② 对补封闭：$\{1\}^c=\{2,3\}\in\mathcal{F}$ ✓；$\{2,3\}^c=\{1\}\in\mathcal{F}$ ✓
  • ③ 可列并：所有有限并都已在 $\mathcal{F}$ 内 ✓

所以 ✅ 是 σ-代数。但注意 $\{2\}$、$\{3\}$ 不在 $\mathcal{F}$ 中——所以这不是最大 σ-代数，也不是"原子可见"的 σ-代数。

Q3 · $\Omega$ 有限时，"$\mathcal{F}$ 是 σ-代数"等价于什么？

等价于"对有限并 / 补封闭"。因为有限集的可列并可以替换成有限并。所以教材例题里只需验证"有限情形下的封闭性"。

Q4 · "所有子集" 是不是平凡 σ-代数？

不是。"所有子集"是最大 σ-代数。平凡 σ-代数是 $\{\varnothing, \Omega\}$——最小。

📌 一句话记忆 σ-代数 = 一族"封闭"的事件集合：装下 $\Omega$、补回来、可列并回来。 概率 $P$ 必须能定义在它的成员上。
