04 · 概率的性质

三条公理看似简单，但能推出所有概率计算会用到的结论。这一页把它们逐一列出并给出证明思路——做题的"弹药库"。

1. 性质速查表

#名称结论
1不可能事件$P(\varnothing) = 0$
2补集$P(A^c) = 1 - P(A)$
3有限可加两两不交的有限事件族 $P(\bigcup_{i=1}^n A_i) = \sum_{i=1}^n P(A_i)$
4单调性$A \subseteq B \Rightarrow P(A) \leq P(B)$
5差集$A \subseteq B \Rightarrow P(B - A) = P(B) - P(A)$
6并集加法$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
7次可加性（有限）$P(A \cup B) \leq P(A) + P(B)$
8次可加性（可列）$P(\bigcup_{i=1}^\infty A_i) \leq \sum_{i=1}^\infty P(A_i)$
9下连续$A_n \uparrow A \Rightarrow P(A_n) \to P(A)$
10上连续$A_n \downarrow A \Rightarrow P(A_n) \to P(A)$

2. 性质 1–3：由公理直接推

性质 1 · $P(\varnothing) = 0$

取 $A_i = \varnothing$，$i=1,2,\dots$。两两不交，且 $\bigcup A_i = \varnothing$。由可列可加性：

$$P(\varnothing) = \sum_{i=1}^{\infty} P(\varnothing) = \infty \cdot P(\varnothing)$$ 若 $P(\varnothing) > 0$，则右端无穷，矛盾。故 $P(\varnothing) = 0$。
性质 2 · $P(A^c) = 1 - P(A)$

$A$ 与 $A^c$ 不相交，且 $A \cup A^c = \Omega$。由有限可加性 + 正则性：

$$1 = P(\Omega) = P(A \cup A^c) = P(A) + P(A^c) \Rightarrow P(A^c) = 1 - P(A)$$
性质 3 · 有限可加性

设 $A_1, \dots, A_n$ 两两不交。取 $A_{n+1} = A_{n+2} = \cdots = \varnothing$ 扩展成可列族。由可列可加性：

$$P\!\left(\bigcup_{i=1}^n A_i\right) = \sum_{i=1}^n P(A_i) + \sum_{i=n+1}^\infty P(\varnothing) = \sum_{i=1}^n P(A_i)$$

3. 性质 4–5：单调性与差集

性质 4 · 单调性

设 $A \subseteq B$。则 $B = A \cup (B - A)$，且 $A \cap (B - A) = \varnothing$。由非负 + 有限可加：

$$P(B) = P(A) + P(B - A) \geq P(A)$$

推论：$P$ 是单调非减的。

性质 5 · 差集公式

由上面的等式直接得：

$$A \subseteq B \Rightarrow P(B - A) = P(B) - P(A)$$

4. 性质 6–7：并集与次可加性

性质 6 · 并集加法公式（最常用）

把 $A \cup B$ 拆成三个不相交部分：

$$A \cup B = A \cup (B - A) = A \cup (B - A \cap B)$$

更标准地，把 $A \cup B$ 分成 4 块：$A \cap B$、$A - B$、$B - A$、$(A \cup B)^c$。直接对 $A, B$ 做有限可加：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
推导

把 $B$ 拆成 $B = (A \cap B) \cup (B - A)$（不相交）。

$$P(B) = P(A \cap B) + P(B - A) \Rightarrow P(B - A) = P(B) - P(A \cap B)$$

又 $A \cup B = A \cup (B - A)$（不相交），故

$$P(A \cup B) = P(A) + P(B - A) = P(A) + P(B) - P(A \cap B)$$
性质 7 · 次可加性（有限情形）

由性质 6 + $P(A \cap B) \geq 0$ 直接得：

$$P(A \cup B) \leq P(A) + P(B)$$
应用 · 三事件容斥（教材重点） $$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(BC) - P(AC) + P(ABC)$$

这是考试里出现频率非常高的公式，证明可对两事件情形反复使用归纳。

5. 性质 8：可列次可加性

性质 8 · 可列次可加性

对任意（不一定不相交的）事件族 $A_1, A_2, \dots \in \mathcal{F}$：

$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) \leq \sum_{i=1}^{\infty} P(A_i)$$
证明思路

定义 $B_1 = A_1$，$B_i = A_i - \bigcup_{j $$P\!\left(\bigcup A_i\right) = P\!\left(\bigcup B_i\right) = \sum P(B_i) \leq \sum P(A_i)$$

这就是Boole 不等式（Boole's inequality）。

6. 性质 9–10：连续性

性质 9 · 概率的下连续性

若 $A_1 \subseteq A_2 \subseteq \cdots \subseteq A_n \subseteq \cdots$（单调递增），记 $A = \bigcup_n A_n$（极限事件），则

$$P(A_n) \uparrow P(A), \quad \lim_{n\to\infty} P(A_n) = P(A)$$
性质 10 · 概率的上连续性

若 $A_1 \supseteq A_2 \supseteq \cdots$，且 $\bigcap_n A_n = A$，则

$$P(A_n) \downarrow P(A), \quad \lim_{n\to\infty} P(A_n) = P(A)$$

（前提是某个 $P(A_n) < \infty$，否则递减趋于 $-\infty$ 没有意义。）

性质 9 的证明思路（下连续）

令 $B_1 = A_1$，$B_i = A_i - A_{i-1}$（$i \geq 2$）。则 $B_i$ 两两不交，$\bigcup_{i=1}^n B_i = A_n$。由可列可加：

$$P(A) = P\!\left(\bigcup_{i=1}^\infty B_i\right) = \sum_{i=1}^\infty P(B_i) = \lim_{n\to\infty} \sum_{i=1}^n P(B_i) = \lim_{n\to\infty} P(A_n)$$
为什么需要连续性？ 连续性是可列可加性的推论，但它反过来又是验证"$P$ 是否构成概率"的强有力工具：只要在所有递增事件族上极限正确，$P$ 一定满足可列可加。在测度论里这两个条件是等价的。

8. 自检问题

Q1 · 已知 $P(A) = 0.7$，$P(A \cup B) = 0.9$，求 $P(B)$ 的范围。

由并集加法公式（性质 6）：

$$P(A \cup B) = P(A) + P(B) - P(AB)$$ $$0.9 = 0.7 + P(B) - P(AB) \Rightarrow P(B) - P(AB) = 0.2$$

下界：$P(AB) \geq 0 \Rightarrow P(B) \geq 0.2$。

上界：$P(AB) \leq P(A) = 0.7 \Rightarrow P(B) \leq 0.7 + 0.2 = 0.9$。

也可以更直观地看：因为 $B \subseteq A \cup B$，由单调性（性质 4）直接得 $P(B) \leq P(A \cup B) = 0.9$。

综上 $\boxed{0.2 \leq P(B) \leq 0.9}$。

易错点：上界不能写成 1——若 $P(B) = 1$ 即 $B = \Omega$，则 $P(A \cup B) = P(\Omega) = 1 \neq 0.9$，矛盾。正确的上界来自"$P(AB) \leq P(A)$"，不是来自"$P(B) \leq 1$"。

Q2 · 证明：若 $A_n$ 两两不交，则 $P(\bigcup A_n) = \sum P(A_n)$。

这其实是可列可加性的直接应用——题目等价于公理 3 本身。如果需要由"两两不交 + 有限可加"推出，需要额外论证；多数教材的版本直接给出可列可加为公理。

Q3 · $P(A \cup B \cup C) = ?$

三事件容斥公式：

$$P(A \cup B \cup C) = \sum P(A_i) - \sum P(A_i A_j) + P(ABC)$$

展开即 $P(A)+P(B)+P(C) - P(AB) - P(BC) - P(AC) + P(ABC)$。

Q4 · 给一列单调递减的事件 $A_n$，其概率收敛到 0 吗？

不一定！例如 $A_n = \{n, n+1, n+2, \dots\}$（$N = \{1,2,3,\dots\}$）。$\bigcap A_n = \varnothing$，$P(A_n) = 1 - 1/n$。故 $P(A_n) \to 1$，不趋于 0。

📌 一句话记忆 补、对、差、并——四个最常用公式：$P(A^c)=1-P(A)$、$P(A\cup B)=P(A)+P(B)-P(AB)$、差集、并集加法（容斥）。
