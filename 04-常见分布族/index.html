第 04 讲 · 常见分布族

把第 03 讲"随机变量"的一般理论落到具体分布上。本讲覆盖 Bernoulli / 二项 / 几何 / 负二项 / Poisson / 均匀 / 指数 / Gamma / 正态 9 个最常用的分布——每一个都给出直观含义 → 严格定义 → 关键性质 → 典型例子 → 易错点。

📘 来源 · 《随机过程及应用》第 1 章（陈良均） 📘 课件 · 王庆先第 1 讲 + 彭江燕第 3 讲（随机变量-2） 📚 教材 · 《排队论》第 1 章（唐应辉等） 🎯 难度 · ⭐⭐⭐

本讲学习目标

学完本讲，你应该能够：

  1. 对 9 个常见分布各自写出：分布列 / 密度 $p_k$ 或 $f(x)$、分布函数 $F(x)$、参数含义、典型场景
  2. 识别"指数族结构"：Bernoulli / 二项 / Poisson / 指数 / 正态 / Gamma 都是指数族——能用统一语言 $\exp\!\bigl(\eta^\top T(x)-A(\eta)\bigr)\,h(x)$ 表示
  3. 掌握 Bernoulli → 二项 → Poisson 三层极限关系（$n\to\infty$ 罕见事件）
  4. 掌握 指数 → Gamma 的关系（$n$ 个独立 Exp 之和 $\sim$ Erlang）
  5. 会用分布函数法 / 单调公式法把第 03 讲 §8 的技巧套到每个具体分布上
  6. 识别"无记忆性"——只有几何分布与指数分布具有无记忆性
  7. 写出正态分布的 3σ 原则并能用其做工程估算

知识图谱

一句话定位 常见分布 = 给第 03 讲的"随机变量 $X$"填上具体的"概率分布"——把抽象的 $p_k,\ f(x),\ F(x)$ 实例化。 它们之间通过"求和 / 极限 / 卷积 / 变换"互相联系，构成了后续所有随机过程和排队论模型的基本构件。
课件主线例子（贯穿本讲）
  1. Bernoulli：抛一次硬币（正面 $1$，反面 $0$，概率 $p$）——第 02 讲 Bayes 例子的基础
  2. 二项 $B(n,p)$：抛 $n$ 次硬币正面次数（王庆先第 1 讲 slide 25–28）
  3. 几何 $G(p)$：第 $k$ 次抛硬币才出现首次正面的次数（首次成功等待）
  4. Poisson $P(\lambda)$：单位时间内到达银行的顾客数（$\lambda=4/\text{min}$）
  5. 均匀 $U(a,b)$：公交车到站时刻在 $[0,10]$ 分钟内均匀
  6. 指数 $\text{Exp}(\lambda)$：相邻两位顾客到达的间隔（与 Poisson 互为镜像）
  7. Gamma / Erlang：第 $n$ 位顾客到达的累计等待
  8. 正态 $N(\mu,\sigma^2)$：测量误差、学生考试成绩（$\mu=75,\sigma=10$）

本讲与前后章的关系

为什么必须把这一讲学扎实？
  • 第 03 讲已经定义了"随机变量 + 分布函数 $F$"——本讲是其具体实例化，不学第 04 讲，第 03 讲只是空架子。
  • 第 05 讲"数字特征与特征函数"——本讲每个分布都有 $E(X), D(X), \Phi(t)$；第 05 讲就是把它们系统化。
  • 第 08 讲"Markov 链"——状态分类、极限分布、平稳分布的计算全部基于本讲的 Bernoulli / 几何 / 二项。
  • 第 10 讲"Poisson 过程"——直接基于本讲的 Poisson 与指数。
  • 第 13 / 14 讲"排队论"——M/M/1 等模型全部由Poisson + 指数 + Gamma 装配而成。

学习建议

  1. 先读 01（Bernoulli / 二项）——这是离散的"种子"，后面所有离散分布都靠它派生。
  2. 02（几何 / 负二项）+ 03（Poisson）——三页对照读，看 "首次成功 → 第 $k$ 次成功 → 大量独立小概率事件的累积"是怎么递进的。
  3. 04（均匀）——最简单的连续型，作为跳板。
  4. 05（指数）+ 06（Gamma / 正态）——这三页是随机过程与排队论的基石，务必把无记忆性与3σ 原则这两个考点记牢。
  5. 每页对照课件原例（王庆先第 1 讲 / 彭江燕第 3 讲），用"场景 → 参数 → 分布"反推练手。
  6. 做自测 10 题。
